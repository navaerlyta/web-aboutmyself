# Web About Myself

Website profil pribadi Nava Erlyta: profil, hobi, dan galeri foto.

🔗 **Lihat web:** https://navalyta.netlify.app/

## Isi Web
- Profil pribadi
- Hobi dan ketertarikan (memasak, baking, musik, film)
- Galeri foto

## Teknologi
HTML, CSS, JavaScript

## Struktur File
- `index.html`: isi dan struktur halaman
- `style.css`: tampilan dan desain
- `script.js`: efek dan interaksi
- `*.jpg`: foto profil dan galeri
